# Replacement and Push Steps

1. Delete the existing `01-emotion-detection-bilstm-attention` folder from the local repository.
2. Copy the replacement folder from this package into the repository root.
3. Replace `.github/workflows/01-emotion-detection-bilstm-attention.yml` with the supplied workflow.
4. Run the four Git commands listed in `PROJECT_01_PLACEMENT_AND_PUSH.txt` at the repository root.
5. Reboot the existing Streamlit application.
