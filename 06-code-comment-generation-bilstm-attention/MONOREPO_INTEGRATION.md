# Monorepo Integration

1. Copy this folder to the root of `bi-directional-lstm-projects`.
2. Copy `.github/workflows/06-code-comment-generation-bilstm-attention.yml` to the root workflow directory.
3. Keep the project requirements inside this project folder.
4. Track `.keras` files with the root `.gitattributes` Git LFS rule.
5. Add the project and demo URL to the root README.
6. Deploy with entrypoint `06-code-comment-generation-bilstm-attention/app/streamlit_app.py`.
